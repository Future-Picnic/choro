# YouTube playlists — private setup drafts

Source: the existing Choro how-to video library. All 61 entries are recording briefs, not completed or uploaded videos.

## 1. Choro Getting Started Crash Course

Beginner playlist · about 26 min. Follow one project from setup to parallel agents, context, design, review, shipping, Orbit, Solo, and mobile.

Visibility during review: **Private**.

- **Meet Choro and the Core Workflow** (1:30) — Builds the mental model for managing several projects and agents from one place.
- **Projects Are More Than Repositories** (1:45) — Shows a project as a durable home for its work and context, not just a repository shortcut.
- **Complete Your First Agent Flow** (2:00) — Teaches the pure agent loop before adding advanced tools or setup.
- **Work from Context: Tasks and Docs** (2:15) — Keeps the original brief attached from implementation through a verified result.
- **Plan the Work Before Building** (2:15) — Shows how uncertain work becomes a clear plan that stays visible while the agent builds.
- **Go from Task to Design to Preview** (2:30) — Connects the brief, visual direction, implementation, and live refinement in one fast story.
- **Run Scripts and Fix Backend Work** (2:30) — Combines repeatable commands, hands-free prompting, and review into a practical backend loop.
- **Explore Code, Files, Terminal, and Database** (1:30) — Maps the technical workspace for the moments when users want direct control.
- **Ask and Add Context Without an Agent** (1:45) — Uses project context for quick answers, then reuses the same context in agent work.
- **Explore Orbit's Project Intelligence** (2:00) — Shows built-in project knowledge and a custom structured view without a deep setup lesson.
- **Ship the Completed Work** (2:15) — Turns finished work into a traceable branch and pull request through one guided flow.
- **Try Parallel Work with Solo** (2:00) — Shows how to run isolated work in parallel without mixing branches.
- **Take Choro with You on Mobile** (1:15) — Ends with the simple mobile promise: the Mac does the work while the phone keeps you connected.
