# Choro generated cover artwork

Created with the built-in ImageGen tool on 2026-09-17, following the request for stronger header artwork. The existing production avatar is unchanged.

Art direction: dark graphite, tactile lavender and violet glass ribbons, pale blue reflections, and coordinated streams of work joining into one sculptural form.

ImageGen did not return the exact requested platform dimensions. Export copies were proportionally resized, padded, or cropped with ImageMagick to meet upload layouts; no logo replacement, retouching, or text regeneration was applied outside ImageGen. Verify the final saved crop in each platform.

The new naming direction is display name **Choro**, preferred handle **chorodev**, website **https://choro.dev**. The covers deliberately avoid platform handles so they remain usable across channels.
