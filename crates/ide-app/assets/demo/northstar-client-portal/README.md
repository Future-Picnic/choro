# Northstar Client Portal

A polished client workspace for a small creative studio. Clients can follow project progress, review files, read updates, and see upcoming invoices from one place.

## Demo scripts

- `python3 scripts/serve.py` starts the local product preview.
- `python3 scripts/verify.py` checks the fixture content without installing dependencies.

The project intentionally uses local demo data so every Choro Demo build is safe and repeatable.
