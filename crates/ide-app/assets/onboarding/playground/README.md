# Choro Playground

This tiny, dependency-free project exists for Choro’s first-run experience.

Run `python3 scripts/serve.py`, then open <http://127.0.0.1:4173>.

The onboarding builds this project in three small passes: a direct agent prompt
creates the home page, `choro_docs/project-story.choro` specifies the second page,
and a prepared Personal task adds the final project-reference gallery.
