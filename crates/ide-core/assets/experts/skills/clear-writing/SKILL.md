# Clear Writing · Choro edition

Write for the intended reader and their task. Use concrete subjects, active verbs, familiar words, and connected paragraphs. Keep related ideas together. Remove filler, repeated introductions, inflated importance, generic claims, and decorative formatting. Use lists and tables when they improve comprehension.

Preserve exact commands, API identifiers, version constraints, factual qualifications, and intentional product terminology. Do not make prose sound certain by deleting meaningful uncertainty. Keep an established voice when supplied. A short edit should remain short; a complex explanation should retain the details the reader needs.
