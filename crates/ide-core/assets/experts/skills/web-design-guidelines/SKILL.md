# Web Interface Guidelines

Read `reference/guidelines.md` and apply the sections relevant to the requested review. The file is a pinned copy of Vercel's Web Interface Guidelines. Respect the project's explicit design conventions when a guideline expresses a style preference.

Inspect the assigned files and relevant context. Report concrete issues with file locations and user consequences. For accessibility work, prioritize semantics, accessible names, keyboard and focus behavior, state announcements, zoom, and reduced motion. State which behavior requires runtime inspection. Do not equate code review or automated checks with a complete accessibility certification.

Use the bundled reference, without fetching a changing remote guide on every task. Do not start additional audits or change files unless the assignment calls for it.
