# Primary Source Research · Choro edition

Identify the question and the decision the answer should support. Read the sources that own the facts: official documentation, source code, specifications, original research, and first-party data. Search results and summaries help discover sources but are not substitutes for reading them.

Check dates, versions, scope, and contradictory evidence. Distinguish a source's claim from your inference. Use popularity as an adoption signal when comparing tools, alongside maintenance, capabilities, dependencies, and relevant limitations. Do not convert repository stars into a claim that an individual skill produces better results.

Return a direct answer or comparison with links near the supported claims, material uncertainties, and a recommendation tied to the user's constraints. Stop when the decision is sufficiently supported; avoid collecting redundant sources. Save a research file only when requested or required by the assignment. Perform the reading in this Expert; Choro already owns delegation.
